# Visão Geral do Projeto

Este projeto é um frontend de uma carteira digital fintech desenvolvido com React, TypeScript e Vite.

## Stack Tecnológico

- **Framework:** React
- **Build Tool:** Vite
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS
- **Roteamento:** React Router DOM
- **Ícones:** Lucide React

## Estrutura do Projeto

A estrutura de pastas principal em `src/` inclui:

- **pages/**: Contém as páginas principais da aplicação (Dashboard, Histórico, Carteiras, etc.).
- **components/**: Componentes reutilizáveis de UI (Sidebar, Header, etc.).
- **context/**: Gerenciamento de estado global (Auth, Theme, Wallet).
- **services/**: Camada de serviço simulada (Mock API).
- **routers/**: Configuração de rotas da aplicação.
- **hooks/**: Custom hooks.
- **@types/**: Definições de tipos TypeScript.

## Status do Desenvolvimento

Atualmente, a aplicação utiliza dados "mockados" (simulados) definidos em constantes locais para simular o comportamento de uma API real.
